## 三、发布与回滚

发布包放置于 233：

```text
/home/yvesyuan/deploy/zhiwei-root-entry-20260719/
```

执行：

```bash
sudo bash /home/yvesyuan/deploy/zhiwei-root-entry-20260719/install-zhiwei-root-entry.sh
```

脚本执行顺序：

| 顺序 | 动作 |
|---:|---|
| 1 | 备份 Nginx 配置、根首页和已有新版资源 |
| 2 | 首次执行时把旧版页面及静态资源复制到 `/2025/` |
| 3 | 将新版构建产物安装到根目录 |
| 4 | 安装 `/2025/`、`/2026/` 与原 AIOps 兼容规则 |
| 5 | 执行 `nginx -t` 并 reload，不重启任何 API 或 Celery |
| 6 | 验证新版 SPA、旧版入口、兼容跳转和新版 API 401 探针 |

失败时脚本自动恢复原根首页与原 Nginx 配置，备份保存至：

```text
/var/backups/zhiwei-root-entry/<UTC时间戳>/
```
