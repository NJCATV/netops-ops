| 登录名 | 冲突类型 | 涉及人员 | 处理 |
| --- | --- | ---: | --- |
| `lining` | 一人的 OA 用户名与另一人的 OSS 账号同名 | 2 | 查询全部候选并逐一校验密码，仅唯一匹配时登录 |

该冲突不能通过简单的 SQL `OR ... first()` 安全处理。新逻辑在密码唯一命中时选择正确用户；零命中或多命中均拒绝并写登录审计，避免串号。
